## 🌟 핵심 기능 및 포트폴리오 특징

1. **🖼️ 3D 렌더 & 2D CAD 연속 시퀀스 뷰어**
   - 3D 하이퍼리얼 투시도와 국가표준 2D 실시도면(평면도, 천장도, 입면도, 부분상세도)을 하나의 끊김 없는 순환 뷰어(예: 1/5 → 5/5)로 탐색 가능합니다.

2. **🍱 Bento Grid & Architectural Warm Luxury UI**
   - 최신 트렌드의 Bento Grid 레이아웃과 감성적인 웜 베이지 & 티크 우드 톤앤매너(`Google Syne` + `Plus Jakarta Sans` + `Pretendard`)를 결합하여 압도적인 시각적 미학을 제공합니다.

3. **📱 모바일(360~390px) 겹침 방지 정밀 레이아웃**
   - 이미지 위 단일 배지 고정 및 텍스트 자동 줄바꿈(`word-break: keep-all`) 처리로 모든 모바일 화면에서 글자 찌그러짐 현상을 원천 방지하였습니다.

4. **📄 A4 이력서 & 자기소개서 원클릭 PDF 출력 엔진**
   - 웹 화면의 수정 사항이 real-time 동기화되며, 채용 공고 표준 글자 수 맞춤 검증과 A4 인쇄 기능을 지원합니다.

5. **🛡️ 면접관 감상 모드 완전 은폐 & 비밀번호 보안**
   - 일반 방문자(면접관)에게는 모든 편집 UI 및 플로팅 바가 100% 은폐되어 정갈한 웹사이트로 작동합니다. (학생 편집 인증: PIN `1234` / 비밀 URL `?admin=1234` / 상단 로고 3회 클릭)

## 🚀 깃허브 웹배포 (GitHub Pages) 4단계 등록 가이드

1. **[GitHub 로그인 및 저장소 생성]**
   - [GitHub.com](https://github.com) 로그인 후 우측 상단 `+` → **`New repository`** 클릭.
   - Repository name에 `portfolio` 또는 `my-portfolio` 입력 후 **`Public`** 선택하고 **`Create repository`** 버튼 클릭.

2. **[파일 업로드]**
   - 생성된 저장소 화면 중앙의 **`uploading an existing file`** 링크 클릭.
   - 컴퓨터의 `index.html` 파일과 `assets` 폴더 전체를 브라우저 화면으로 드래그 앤 드롭 업로드.
   - 하단 **`Commit changes`** 초록색 버튼 클릭.

3. **[GitHub Pages 활성화]**
   - 저장소 상단 탭에서 **`Settings`** 클릭 → 좌측 메뉴에서 **`Pages`** 선택.
   - Build and deployment 구역의 Branch를 `None`에서 **`main`** (또는 `master`)으로 변경, 폴더는 **`/ (root)`** 선택 후 **`Save`** 클릭.

4. **[내 포트폴리오 주소 확인]**
   - 약 1~2분 후 페이지 상단에 **`Your site is live at https://사용자이름.github.io/portfolio/`** 문구와 배포 링크 생성.
   - 생성된 링크를 이력서 및 채용 사이트 포트폴리오 URL 입력란에 제출합니다.
