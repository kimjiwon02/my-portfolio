## 🌟 핵심 기능 및 포트폴리오 특징

1. **🖼️ 3D 렌더 & 2D CAD 연속 시퀀스 뷰어**
   - 3D 하이퍼리얼 투시도와 국가표준 2D 실시도면(평면도, 천장도, 입면도, 부분상세도)을 하나의 끊김 없는 순환 뷰어(예: 1/5 → 5/5)로 탐색 가능합니다.
   - 제외(숨김) 처리된 도면은 뷰어 및 미리보기에서 100% 자동 제외됩니다.

2. **📄 A4 이력서 & 자기소개서 원클릭 PDF 출력 엔진**
   - 웹 화면의 수정 사항이 real-time 동기화되며, 채용 공고 표준 글자 수 맞춤 검증과 A4 인쇄 기능을 지원합니다.

3. **🛡️ 면접관 감상 모드 완전 은폐 & 비밀번호 보안**
   - 일반 방문자(면접관)에게는 모든 편집 UI 및 플로팅 바가 100% 은폐되어 정갈한 웹사이트로 작동합니다.
   - 비밀번호 인증: 기본 PIN **`1234`** / 비밀 URL **`?admin=1234`** / 상단 로고 3회 클릭

4. **💾 정적 웹 호스팅 영구 저장 엔진 (`exportCurrentWebsiteHTML()`)**
   - 브라우저에서 편집 후 **`[ 💾 수정본 영구 저장 ]`** 버튼을 클릭하면 다운로드되는 `index.html`을 저장소에 업로드하는 것만으로 최신 데이터가 영구 반영됩니다.

## 🚀 깃허브 웹배포 (GitHub Pages) 4단계 등록 가이드

1. **[GitHub 로그인 및 저장소 생성]**: GitHub.com에서 `New repository` (이름: `portfolio`, `Public` 선택) 생성.
2. **[파일 업로드]**: `index.html`, `README.md`, `.gitignore` 파일과 `assets` 폴더 전체를 드래그 업로드 후 `Commit changes`.
3. **[GitHub Pages 활성화]**: 저장소 `Settings` -> `Pages` -> Branch: `main` / `/ (root)` 선택 후 `Save`.
4. **[웹 포트폴리오 주소 확인]**: 약 1~2분 후 `https://사용자계정.github.io/portfolio/` 주소로 즉시 접속 가능.
